openssm_

A read-only Subaru Select Monitor reader for macOS, in Zig. Drives a Tactrix OpenPort 2.0 over USB and serves live SSM data over JSON IPC.

● hardware bring-up done Zig 0.15 macOS · CDC-ACM · no sudo SSM2 · SSM3 · SSM4 read-only

What it is

Subaru diagnostics live in three eras: SSM2 on the 4800-baud K-line, SSM3 as SSM-over-CAN, and SSM4 as UDS/ISO14229 for 2007+ vehicles. openssm aims for close to 1:1 parity with the read functions of the dealership SSM3/SSM4 tools.

It is a hardware daemon: one process owns the OpenPort and speaks the protocols, then exposes a JSON-lines endpoint so a CLI, GUI, logger, or dashboard can all build on the same data. No J2534 DLL, no Windows, no Wine.

Architecture

Quick start

# build + test
zig build && zig build test

# device info + battery voltage
./zig-out/bin/openssm probe

# open the K-line SSM channel, send ECU init
./zig-out/bin/openssm kline

# serve IPC (or: mock-serve to develop clients with no car)
./zig-out/bin/openssm serve --unix /tmp/openssm.sock

# query it
printf '{"id":1,"method":"probe"}\n' | nc -U /tmp/openssm.sock
# {"id":1,"result":{"firmware":"main code version : 1.17.4877","vbatt_mv":0}}

Roadmap

1 · Live K-line read

Confirm SSM init on the car, implement 0xA8 address reads with RomRaider scaling.

2 · SSM3-CAN + UDS

SSM-over-CAN IDs, then VIN, DTCs and freeze frame over ISO14229.

3 · Parameter database

Parse RomRaider log_defs.xml / ecu_defs.xml into named parameters.

4 · Streaming IPC

Subscriptions, live push, optional msgpack framing.

read-only by design — no flash writes, no ECU programming.  ·  github.com/danfragoso/openssm
